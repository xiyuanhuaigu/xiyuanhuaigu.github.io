# 三.激活 Navicat

## 1.获取注册机

[蓝奏云](https://wwt.lanzouv.com/inIf609eai0h)  
密码:a8a6

## 2.使用注册机

注意：关闭网络，关闭所有杀毒软件，WIN10/11 系统需关闭 Windows Defender 的实时保护  
下载成功之后使用管理员身份打开注册机

### 设置安装路径，点击 Patch

安装路径为Navicat安装路径

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/RWniK3Ct2R.png)

出现提示，点击是

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/oWwclfeQwQ.png)

### 生成许可证

在 KeyGen 中选择软件，版本，语言后，点击 Generate，生成许可证

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/DYiwKU34HE.png)

同时打开 Navicat Premium，点击注册

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/5LSALcFPjA.png)

将生成的许可证复制到下图位置

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/178glrk9U0.png)

### 手动激活

点击激活后，会出现服务器不可用提示，点击手动激活

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/psMmZmVXM0.png)

1. 点击手动激活之后，只会出现激活码，将激活码复制到 Request Code 框中
2. 点击 Generate Activation Code，会在 Activation Code 框中生成激活码
3. 将 Activation Code 框中的激活码复制到左边的激活码框中，点击激活

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/Co0EQYzdSv.png)

点击激活之后成功会出现永久许可证标识

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/9BlmY48hYj.png)

进入 Navicat 软件，点击帮助→关于，查看激活信息

![](https://xyhutc.oss-cn-qingdao.aliyuncs.com/giteetuchuang/gRLe9XdWAC.png)
